## Hey, I'm Priyadharshan

I'm a software engineer in Chennai who's drawn to the systems behind the product: how services talk to each other, how platforms stay up, and how to make the whole thing nicer to work with.

Most of my side projects start with something I want to use myself, from inspecting coding-agent sessions to managing my clipboard and keeping a daily work log. I also contribute to open source and build learning resources as I go.

- **Now:** Production Engineering on Workday's Developer Platform
- **Building:** a Redis clone in Go, the first of a few from-scratch distributed systems
- **Teaching:** [Golang Academy](https://priyadharshan0903.github.io/golang-academy/), a free, open source Go curriculum
- **Contributing:** Git workflow improvements in [Zed](https://github.com/zed-industries/zed)

## Featured projects

### Runlens

**See what your coding agents actually did.**

A local viewer for **Claude Code** and **Codex** sessions. Browse conversations, inspect tool calls and recorded file changes, follow subagents, and search past work. It reads the history already on your machine: no API key, no uploads.

```sh
npx runlens@latest
```

### Corral

**Keep the image. Copy the words.**

A macOS menu bar clipboard manager. It keeps copied screenshots alongside your text history, pulls text out of images with on-device OCR (Apple Vision), saves named snippets, and opens right beside your mouse pointer with a global shortcut. Everything stays on your Mac.

[![Corral website](https://img.shields.io/badge/Live%20site%20%E2%86%97-Corral-000000?style=for-the-badge&labelColor=3a3a3a)](https://priyadharshan0903.github.io/Corral-Releases/)
